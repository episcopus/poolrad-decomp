# Contributing

Thanks for looking. Issues, questions and pull requests are welcome; this file says how they are handled, so nothing is a surprise.

## How this repository works

This repository is a published copy of a private working repository, written by a sync and never edited here by hand. That has one consequence for pull requests:

- A pull request is never merged on GitHub. If it is taken, the change is applied in the working repository, with you credited as co-author (`Co-authored-by`), and arrives here with the next sync; the pull request is then closed with a link to that commit.
- So keep a pull request small and about one thing, and say why in its description. A bug report with a clear way to reproduce it is often just as useful as a fix.

## Issues

- Bugs: use the bug report form. Say which part you ran (the Pascal rebuild, the C translation, the CoCo 3 port, the maps, a tool), on what, and how to reproduce it.
- Ideas and questions: use the idea form, or the project site, https://anonymousformula.com/poolrad/.
- There is no promise of a reply time. This is a project done for fun.

## The game's files

The game is still sold, and its files are not in this repository. Never attach, link or paste them (the DAX archives, the executables, disk images, ROMs, saved games) in an issue, a pull request or a commit, and do not ask for them. Issues or pull requests that do are closed and the files removed. You need your own copy of the game to run the rebuild or the ports.

## Conduct

Be kind and stay on topic. Personal attacks, harassment and spam are removed, and their authors blocked.
