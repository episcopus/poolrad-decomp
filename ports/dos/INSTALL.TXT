POOL OF RADIANCE (PC), REBUILT FROM ITS DECOMPILED SOURCE: NO CODE WHEEL, FASTER

This is the PC game (version 1.3) linked again from its decompiled Turbo
Pascal source, with these changes:

- The game no longer asks for a code word from the translation wheel. The
  title screens play, then the character menu comes up.
- A hang of the original is fixed: in combat, a character on Quick whose
  readied weapon is darts could freeze the game when an enemy stood next to
  it (the character's panel redrawn over and over, no key answered). Such a
  character now throws its darts and the battle goes on.
- The game is faster. On Tandy video (POOL.CFG video T) the drawing: text,
  the 3D view, sprites, pictures, window clears. On every machine: loading
  and the line-of-sight work of combat. An emulated 8088 at 7.16 MHz with
  Tandy video needs about half the time or less
  for a step in the 3D view, a third for a combat turn, a fifth for a menu
  key. The game plays exactly as before: same screens, same dice, same saved
  games (checked on every key of 12 recorded sessions).

Everything else is the original program: same graphics modes (EGA, CGA,
Tandy), same sound devices, same saved games.

FILES

  START.EXE   the game program (replaces the original START.EXE)
  GAME.OVR    its overlay file (replaces the original GAME.OVR)

The two files belong together. Never mix this START.EXE with the original
GAME.OVR, or the original START.EXE with this GAME.OVR: the game would crash
the first time it loads an overlay.

INSTALL

1. Install the original game as usual (its own install program or copy), and
   run it once to check that POOL.CFG says what you want (video T and sound T
   on a Tandy 1000).
2. Keep a copy of the original START.EXE and GAME.OVR, for example:
     COPY START.EXE START.ORG
     COPY GAME.OVR GAME.ORG
3. Copy START.EXE and GAME.OVR from this folder over the originals.
4. Start the game the usual way: START

To go back, copy START.ORG to START.EXE and GAME.ORG to GAME.OVR.

Saved games, POOL.CFG and every data file are unchanged and shared with the
original program.

SIZES

START.EXE is not compressed (the original is packed with EXEPACK), so it is
about 6 KB larger on disk; GAME.OVR is about 1 KB smaller. The game needs
about 0.5 KB more memory to run (the faster code). SHA256.TXT lists the
checksums of both files.
