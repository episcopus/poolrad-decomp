The comment is true ("the Status BandageDying gives a dying character"); the name hides that the bandaged character is unconscious (stable at 0 hit points [I]). Prefer `StatusUnconscious` with the bandage in the comment, or record the harmonisation for Phase 6. Likewise `StatusBledOut = 6` is ovl04's `StatusGone` (Raise Dead accepts 1 and 6): one name for both.

OVL24 names the kinds its own rolls use (HookDamage = 6, HookSave = $C, ...) and says "other units call it with 7, $F and $13"; name them here by their call sites (turn start, before the character acts or the menu is built, round end) so a port can tell them apart, or share OVL24's constants.
- [ ] should-fix the `dsXXXX` globals this unit decides: `ds6E30` is documented as "the Alt-M Magic On/Off toggle" and the unit shows the strings "Magic On"/"Magic Off" (`MagicOn`), `ds6DE3` as "counted up once per combat round" (`CombatRound`), `ds6E31` as "the key flag the ovl08 menus pass to ReadPromptChoice" (it is a dummy ExtKey sink: `MenuKeyFlag`), and `ds6814`/`ds6815` are the side counts (POOLVARS `ds6814Sides` says they are indexed by side in ovl10:1AC7, side 0 the party, and this unit's own test `ds6814 > 0 and ds6815 = 0` for "only the enemies are gone" agrees).
